# BRIDGE APP 3.0 — 모바일 퍼스트 V1

## 무엇을 만들었나
- 모바일 중심 홈/하단 5탭, 애니메이션/모달/터치 피드백. PC에서는 좌측 탐색 레일과 넓은 업무 화면.
- 원장·강사·회원 분리된 화면과 관리자 체험 화면. 기존 V2.2 브랜드 자산 일부 사용.
- **직접 수정 가능한 시연 관리자**: 강사 추가/수정/삭제, 센터 추가/수정/삭제, 회원권 조정(사유 기록), 공고 추가, 구독료·수수료·홈 문구 수정, 브라우저 로컬 백업/복원.
- 원장 공고 → 강사 지원 → 원장 비교/수락 → **해당 그룹 예약 회원에게만** 시연 알림. 회원은 확인 또는 변경 이유로 취소하며 그룹 이용권 회차 복구.
- 강사 탐색(홍대입구역 5km 시연 데이터), 회원 개인 레슨 시연 예약, 회원만 작성하는 공개/비공개 태그 후기.
- 모바일 PWA(홈 화면 설치 구성) + 상대 경로 사용으로 GitHub Pages 하위 경로 `/bridge-app/` 지원.

## 반드시 알아야 할 한계
- **이 ZIP은 첫 번째 동작형 프런트엔드 프로토타입입니다.** 관리자 변경 내용은 현재 브라우저 `localStorage`에만 저장. 다른 스마트폰/PC에는 반영되지 않음. 실제 Firebase/Supabase 공용 DB, 보안 로그인, PG 결제, 외부 푸시, 회원별 권한 통제 미구현.
- 역할 변경 버튼으로 누구나 시연 관리자로 들어갈 수 있어 **실제 개인정보를 입력하면 안 됩니다**.
- 예약·후기·강사 정보는 시연 데이터이며 근로자 알선 수수료 및 예약 취소 조항 등은 사업화 전 법적 검토가 필요합니다.
- 기존 2.2 파일은 손대지 않았고 이 ZIP은 모바일 화면을 새로 만든 별도 개발본입니다. 과거 모든 부가 기능을 완전히 옮긴 것은 아닙니다.
- 일부 시연 버그 및 접근성 문제는 후속 테스트·개선 필요.

## GitHub Pages 배포(기존 bridge-talk 절대 덮어쓰지 않기)
1. `odduxxx-blip/bridge-app` 새 저장소의 **최상위**에 이 폴더 안의 `index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, `assets/`, `icons/`를 올립니다. **바깥 폴더째 업로드하지 마세요**.
2. Settings > Pages > Deploy from a branch > `main` / `/ (root)`.
3. Actions의 Pages 빌드 성공을 확인합니다.
4. 주소: `https://odduxxx-blip.github.io/bridge-app/` (실제 배포 완료 후 확인).
5. 이전 버전의 서비스 워커 캐시로 화면이 구버전이면 시크릿 창 또는 사이트 데이터 초기화 후 재확인.
6. QR은 위 **실제로 열리는 URL**을 대상으로 만든 후 발표에서 사용합니다.
