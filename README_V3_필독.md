# BRIDGE APP 3.0 V3 — 모바일 디자인 유지 + 기능 복원

## 변경 원칙
- V2에서 승인된 시작 화면 레이아웃, 모바일 하단 탭, 내부 히어로 배너·색상·움직임 유지.
- 로그인/시작 화면의 원장·강사·회원 이미지 3개만 새 BRIDGE 연결 일러스트로 교체.
- 기존 2.2의 확정 정책 유지: 원장 공고 → 강사 지원 → 원장 수락 → 본인 예약 회원 알림.
- 실결제·계정 로그인·공용 데이터베이스가 연결되지 않은 **브라우저 전용 시연본**.

## V3에서 모바일 네이티브 메뉴로 추가한 기능
- 원장: 그룹 수업 일정, 출석 확인과 회원권 차감, 매출 등록·내역, 재등록 쿠폰 발급·사용 처리, 그룹 예약 관리, 커뮤니티.
- 강사: 개인 레슨 예약 회원 확인 및 수업 완료 기록, 프로필 수정·보정 이행률·수업 이력, 강사 라운지·답글.
- 회원: 내 회원권 및 사용/복구 기록, 센터 탐색, 그룹 수업 예약, 개인 레슨 예약(예약금·취소 안내 동의), 본인 예약 분리, 태그 후기, 커뮤니티.
- 관리자: 강사·센터·회원·요금·공지 편집, 공고, 일정, 쿠폰, 매출, 게시글, 변경 이력(시연).
- 공통: 기존 10명 강사, 회원 2명, 홍대 5km 필터, 공개·비공개 후기, 대강 및 개인 레슨 시연 수수료.

## 기존 2.2 보존
- `legacy/index.html`에 2.2 원본 웹을 수정 없이 포함.
- 원장·강사·회원의 '더보기'에서 **2.2 전체 기능 원본 열기** 가능.
- 2.2 원본과 V3의 브라우저 데이터는 각각 독립 저장. **양쪽 자료가 동기화되지는 않음**.
- V3 기능 추가는 완전한 상용 서버 이식과 다름. 개별 세부 화면/예외 흐름은 추가 검증 필요.

## 배포
- `bridge-app` GitHub 저장소 `main` 브랜치의 루트에 이 ZIP 압축을 푼 **내용물 전체** 업로드.
- 최상위에 반드시 `index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, `assets/`, `icons/`, `legacy/`가 보여야 함.
- Settings → Pages → Deploy from a branch → main → / (root).
- 배포 확인 주소 예시: https://odduxxx-blip.github.io/bridge-app/
- 구형 서비스워커 캐시가 남으면 Ctrl+Shift+R 혹은 브라우저 사이트 데이터/캐시 정리로 갱신.
- **발표용 `bridge-talk` 저장소와 사이트는 절대 덮어쓰지 말 것.**

## 검증 범위
- Node.js JavaScript 문법 검사 통과.
- Playwright(브라우저 렌더링)에서 DOM 주입 방식으로 모바일 390px 화면 클릭 테스트: 원장 메뉴, 출석 확인, 매출 등록, 쿠폰 발급, 회원 전환, 회원권, 그룹 예약, 개인 레슨 예약, 커뮤니티 글쓰기, 강사 레슨 목록 실행·자바스크립트 오류 없음.
- 모바일 시작 화면의 실제 이미지·레이아웃은 브라우저에서 미리보기 캡처 검수.
- 로컬/인터넷 서버로 접속하는 Playwright 실행은 환경 차단 때문에 못 했으므로 HTTPS 배포 실기기 테스트는 **미완료**.
- Android/iOS PWA 설치, 실제 회원 인증, DB 동기화, PG 결제, 외부 푸시, 관리자의 보안 권한은 **미구현**.

## 사용 시 주의
- 역할은 시연을 위해 자유롭게 바꿀 수 있음. 개인정보가 실제로 보호되는 인증 시스템이 아님.
- 회원권·수수료·후기·이행률은 데모 데이터이며 실적이 아님.
- 24시간 전 취소, 예약금·노쇼 처리 문구는 시연/기획 안내이고 법적 확정 약관이 아님.
- 백업은 ‘더보기’의 JSON 내보내기를 사용.
