# BRIDGE APP 3.0 V4 — 모바일 UX 정렬 개선

## 이번 수정 범위
- V3의 색감·배너·시작 화면·역할별 기능과 로컬 데이터 키 보존
- 모바일 320/360/390/430px 기준 카드 패딩·높이·그리드·메뉴·터치 영역 통일
- 하단 탐색 버튼 터치 영역 확대, 활성 상태 배경 강조
- 더보기 속 기능 화면에서 뒤로 이동할 수 있는 별도 버튼
- 예약 팝업에 가격 요약·날짜/시간·취소 정책 동의·확정 버튼을 구획해 좁은 화면에서도 정렬
- 시연용 예약은 실제 결제가 발생하지 않음을 반복 명시
- 모션은 기존 V2/V3의 절제된 효과 유지

## 제약과 작업 순서
- 모든 사용자 계정은 시연 역할 선택이며 실제 인증이나 PG 결제가 아니다.
- 관리자/사용자 데이터는 같은 브라우저 localStorage에만 저장, PC↔모바일 공유되지 않는다.
- 전체 2.2 원본 기능이 V4에 완전히 이식된 상태가 아니다. V4는 V3의 모바일 사용성·정렬 집중 개선본이다.
- 원본 2.2 및 발표용 github 저장소는 수정하지 않았다.

## GitHub 배포
- 개발용 bridge-app 저장소 최상위에 이 ZIP 압축 해제 내용 업로드.
- index.html, app.js, assets/, icons/, manifest.webmanifest, sw.js가 루트에 있어야 한다.
- Actions 새 배포 완료 후 시크릿 브라우저에서 열어 캐시 영향 구분.
